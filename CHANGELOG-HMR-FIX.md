# Changelog - Исправление проблем с HMR и стабильностью frontend

## Дата: 2026-05-04

### Проблема
- Ошибки "Cannot find module './XXX.js'" в Next.js dev режиме
- Периодическое пропадание стилизации
- Нестабильная работа Hot Module Replacement (HMR)

### Внесенные изменения

#### 1. Обновлен `apps/web/package.json`
- ✅ Добавлен скрипт `dev:clean` для запуска с очисткой кеша
- ✅ Добавлен скрипт `clean` для ручной очистки кеша
- ✅ Добавлена зависимость `rimraf` для кроссплатформенного удаления файлов

#### 2. Улучшен `apps/web/next.config.js`
- ✅ Отключено webpack кеширование в dev режиме
- ✅ Увеличен таймаут `onDemandEntries` до 60 секунд
- ✅ Увеличен буфер страниц до 5

#### 3. Созданы вспомогательные файлы
- ✅ `clean-cache.ps1` - PowerShell скрипт для быстрой очистки кеша
- ✅ `TROUBLESHOOTING.md` - подробное руководство по решению проблем
- ✅ `QUICK-START.md` - быстрая памятка для разработчиков
- ✅ Обновлен `README.md` с ссылками на troubleshooting

### Как использовать

#### При возникновении ошибки "Cannot find module"
```powershell
.\clean-cache.ps1
npm run dev
```

#### Запуск с автоматической очисткой
```powershell
npm run dev:clean --workspace=apps/web
```

#### Ручная очистка кеша
```powershell
npm run clean --workspace=apps/web
```

### Профилактика
- Периодически очищайте кеш при активной разработке
- Используйте `dev:clean` после долгого перерыва
- Не делайте слишком быстрые изменения в коде

### Технические детали
- Webpack кеш отключен в dev режиме для предотвращения конфликтов модулей
- Увеличен таймаут для предотвращения преждевременного удаления страниц из памяти
- Добавлены удобные команды для очистки кеша
