# Troubleshooting Guide

## Проблемы с Next.js в режиме разработки

### Ошибка "Cannot find module './XXX.js'"

**Симптомы:**
- Ошибка `Error: Cannot find module './296.js'` (или другой номер)
- Пропадает стилизация на сайте
- Страницы не загружаются после изменений в коде

**Причина:**
Webpack Hot Module Replacement (HMR) создает временные чанки, которые удаляются быстрее, чем сервер успевает их загрузить. Это происходит при:
- Быстрых изменениях файлов
- Устаревшем кеше `.next`
- Конфликтах между старыми и новыми модулями

**Решения:**

#### 1. Быстрое решение (рекомендуется)

```powershell
# Остановить dev-сервер (Ctrl+C)
npm run clean --workspace=apps/web
npm run dev:web
```

Или используйте PowerShell скрипт:
```powershell
.\clean-cache.ps1
npm run dev
```

#### 2. Запуск с автоматической очисткой кеша

```powershell
npm run dev:clean --workspace=apps/web
```

#### 3. Полная переустановка (если проблема сохраняется)

```powershell
# Удалить все зависимости и кеш
Remove-Item -Recurse -Force node_modules, apps\web\.next, package-lock.json

# Переустановить
npm install

# Запустить
npm run dev
```

### Пропадание стилизации

**Причина:**
CSS-модули не успевают загрузиться при HMR или конфликт Tailwind CSS.

**Решения:**

1. **Очистить кеш** (см. выше)

2. **Жесткая перезагрузка в браузере:**
   - Windows: `Ctrl + Shift + R` или `Ctrl + F5`
   - Mac: `Cmd + Shift + R`

3. **Проверить Tailwind конфигурацию:**
   ```bash
   # Убедитесь, что Tailwind правильно настроен
   cat apps/web/tailwind.config.js
   ```

### Медленная работа HMR

**Решение:**
Уже применено в `next.config.js`:
- Отключено кеширование webpack в dev режиме
- Увеличен таймаут для `onDemandEntries`

### Проблемы с Docker

Если используете Docker и возникают похожие проблемы:

```bash
# Пересобрать контейнеры без кеша
docker-compose down
docker-compose build --no-cache
docker-compose up
```

## Полезные команды

```powershell
# Очистка кеша Next.js
npm run clean --workspace=apps/web

# Запуск с чистым кешем
npm run dev:clean --workspace=apps/web

# Проверка зависимостей
npm audit

# Обновление зависимостей
npm update

# Просмотр логов в реальном времени
npm run dev:web
```

## Профилактика

Чтобы минимизировать проблемы:

1. **Не делайте слишком быстрые изменения** — дайте HMR время на обработку
2. **Периодически очищайте кеш** — раз в день при активной разработке
3. **Используйте `dev:clean`** при первом запуске после долгого перерыва
4. **Следите за обновлениями Next.js** — многие проблемы HMR исправляются в новых версиях

## Дополнительная помощь

Если проблема сохраняется:
1. Проверьте логи в терминале
2. Откройте DevTools браузера (F12) и проверьте Console и Network
3. Создайте issue с полным стектрейсом ошибки
